# KNIME workflow kaydı (zorunlu — senin yapman gereken tek adım)

Cursor gerçek `.knwf` üretemez; dosya KNIME’dan export edilmelidir.

## Adımlar
1. KNIME’da `01_Kumeleme_Enerji` workflow’unu aç
2. **File → Export KNIME Workflow…** (veya workflow’a sağ tık → Export)
3. Hedef klasör:
   `C:\Users\HP\energy-knime-project\knime\`
4. Dosya adı önerisi:
   `01_Kumeleme_Enerji.knwf`
5. Export tamamlanınca bu klasörde `.knwf` görünmeli

## Kontrol
```
knime/01_Kumeleme_Enerji.knwf
```
